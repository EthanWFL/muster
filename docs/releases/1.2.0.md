# Muster 1.2.0

本版集中改善技能管理、Agent 导航和会话操作。技能页改为全宽列表，本机发现的技能可直接向其他 Agent 启用；会话行右侧显示运行客户端图标，点击可切回对应应用。

## 技能管理

- 技能库按来源分组，支持折叠、搜索和批量选择；详情按需打开，默认阅读 Markdown，编辑操作放到第二层。
- 技能行只显示 Agent Logo：已启用显示原色，未启用置灰；所有图标按设置中的 Agent 管理清单展示。
- 本机发现支持自动收录并启用完整技能包，以名称和内容指纹关联相同技能，同名不同内容保持独立。
- 独立目录中的技能支持可逆停用：保留原目录或链接，再次开启时原样恢复。文件变化、恢复路径被占用或父目录被替换时停止操作。
- 行内启停只处理点击的 Agent。正常接管自动备份，停用时还原；批量操作与异常恢复保留预览。
- 修复新部署被共享目录规则误判、再次点击无法撤销的问题。无法单独关闭的外部共享来源，点击图标会显示原因及来源，不再无反馈。
- 部署状态与磁盘不一致时，可清除失效记录、仅解除管理，或备份后重新接管；外部文件和原备份保留。
- 新增 DeepSeek Harness、Hermes、Cursor 的技能目录适配，保留原有 Claude Code、Codex、Pi 支持。

## 会话与菜单栏

- 菜单栏图标旁显示当前管理范围内的运行会话总数，不计历史记录。
- 从父进程链识别 Warp、Terminal、iTerm、VS Code、Cursor、Codex、ChatGPT 等运行客户端，在会话行右侧显示其本机应用图标。
- 点击客户端 Logo 只激活已运行的应用，不执行终端定位、复制恢复命令或启动新会话。会话页旧的终端操作入口已移除。
- 来源不明确、经过 tmux/screen/SSH、无法关联进程或进程已退出时不强行标注，不把实时来源写入历史记录。

## 界面调整

- Agent 的规则、技能、配置移到左侧二级菜单，移除大小窗口重复的 Agent 筛选下拉；管理范围统一由设置控制。
- 配置保留具体 Agent 的编辑入口和“全部配置”返回入口，切换时保护未保存内容。
- 规则小面板默认收起正文与摘要，点击右侧箭头才展开。
- 管理窗口默认 1000 × 680，侧栏收窄，保留用户尺寸与位置记忆。
- 修复下拉按钮图标放大，以及项目等长页面滚动覆盖标题栏、搜索按钮和页脚的问题。

## 验证与边界

- 315 项自动化测试通过，涵盖技能接管、撤销、原件恢复、中断恢复、外部修改保护、Agent 范围、会话来源和窗口布局。
- 使用包含 50 条会话的测试项目验证了管理窗口滚动边界。
- 技能图标表示根据本地目录判断的可见状态，不保证运行中的 Agent 已重新加载。共享目录的外部技能无法安全地只对其中一个读取者关闭；撤销 Muster 部署后，若仍有其他来源，图标会继续显示启用并说明原因。
- 客户端 Logo 激活应用，不保证定位到具体标签页或桌面端线程。
- 支持 macOS 14+、Apple Silicon。应用采用 ad-hoc 代码签名，未经过 Apple 公证；正式安装包另附 Ed25519 更新签名及 SHA-256 校验文件。
