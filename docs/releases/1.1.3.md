# Muster 1.1.3

把技能部署的控制放回列表行内，补上 Agent 的真实图标，并让管理窗口跟随当前桌面打开。

## 技能部署

- **列表行内直接启停。** 每行右下角显示已纳入管理的 Agent 徽标，点一下即启用或停用，无需先切到详情页。悬停提示会写出该 Agent 的目标目录。
- **右键切换链接方式。** 对已启用的 Agent，右键徽标可在符号链接与副本之间切换；已启用的项会置灰。
- **只有需要接管时才预览。** 无冲突的变更立即按事务应用；目标目录已被同名技能占用时，仍会打开预览等待逐项确认，且预览范围只针对点击的那个技能，不会把当前正在编辑的技能或批量勾选带进去。
- **详情页不再重复部署面板。** 未勾选多个技能时详情页只保留编辑器；批量部署面板仅在勾选多个技能时出现。没有任何可用 Agent 时，直接说明该去「设置 → Agent 管理」启用哪一个。

## 界面

- Agent 下拉菜单和设置页的 Agent 行显示官方 logo，新增 Pi、Hermes、Warp、Magpie、OpenCode 图标；读不到图标时仍退回单字徽标。菜单项图标按 AppKit 的菜单尺寸重新绘制，避免在菜单里被拉伸或缩成原图尺寸。
- 管理窗口加入 `.moveToActiveSpace`：在别的桌面打开时会在当前空间出现，不再把用户拽回窗口上次所在的桌面。

## 验证

`Scripts/test.sh --no-parallel` 全部通过（新增行内启停、链接方式切换，以及“占用目录时预览只包含被点的技能”三项模型测试；窗口测试新增 `.moveToActiveSpace` 断言）。发布前对最终 DMG 的签名、公钥、应用版本及 SHA-256 做一致性检查。

## 安装

从 1.1.1 起正式构建内置固定的更新公钥，可在「设置 → 关于」点击「下载并安装」完成更新。**1.0.0、1.1.0 等没有内置公钥的旧版本仍需手动安装一次。** 安装包仍支持 macOS 14+、Apple Silicon（arm64），使用 ad-hoc 代码签名，尚未经过 Apple 公证。
