# Muster 1.3.3

## 管理窗口

- 侧栏改为统一的目标列表：工作区、AI 对话、轮盘配置和设置使用同一套选中与键盘导航，不再需要先展开再点击子项。
- Agent 页在窗口内提供「规则 / 配置 / 技能」分段切换。
- 设置和轮盘配置顶部提供分区跳转，滚动时选中项仍会跟随。
- `⌘F` 只作用于当前页面：项目页搜索项目，Agent 页搜索技能，会话页搜索会话；设置页不再被切走。

## 轮盘

- 各模块固定在自己的扇区，开关某个模块不会再让其他扇区换位置。
- 指针在熊猫上停留片刻才展开，点击可展开或收起，切到其他应用时自动收起。
- 熊猫右键提供「轮盘配置 / 隐藏轮盘 / 重置位置」。
- 常用项目可调整顺序；项目与网页可以选择默认打开的应用，未安装时回退到系统默认。
- 轮盘配置和飞出行都显示模块名与条目图标；项目与网页条目提供「在 Finder 中显示 / 复制路径 / 复制链接」。
- 打开失败时改为内联提示，不再弹出模态对话框。

## 稳定性与可访问性

- 退出前检查会话备注、共享规则、Agent 配置和技能草稿，有未保存内容时先确认。
- 会话扫描失败会显示在诊断页，会话列表区分「扫描中」「扫描失败」和「没有会话」。
- 文字改用系统语义字号，控件和图标点击区扩大到 28pt；分段控件支持左右方向键。

## 内部调整

- 会话扫描与各功能模型收进 `AppEnvironment`，`PanelModel` 只负责导航与选中状态。
- Agent 能力拆成规则、配置、技能、进程四类协议，新增客户端宿主统一由 `ClientHostRegistry` 声明。

支持 macOS 14 及以上、Apple Silicon。DMG 附有 Ed25519 更新签名和 SHA-256 校验文件。应用采用 ad-hoc 代码签名，尚未经过 Apple 公证。
