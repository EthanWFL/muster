# Muster 1.1.0

本次更新把常用 Agent 操作放回小窗口，并补齐项目工作台、独立技能库和统一的 Agent 管理范围。

## 本次交付

- **小窗口直接操作**：Agent 页提供规则／配置两个小 Tab，首次默认规则，之后记住上次选择。当前规则集默认展开，Agent 开关按单行排列，预览、应用、放弃和保存按钮固定在底部。配置页直接显示具体 Agent 的已有配置能力，支持模型、服务商和预设操作；技能入口直达管理窗口。
- **大小窗口协作**：共用规则与配置草稿，分别记住页签。展开定位当前规则或配置，切换 Agent 时保留保存／放弃／取消提示。
- **项目工作台**：手动添加项目文件夹，或从会话发现项目；支持搜索、固定、改名及移出列表。项目详情汇总相关会话、待处理事项、备注和产物目录，并可继续会话。
- **独立技能管理**：支持本地文件夹、已有 Agent 技能和公开 HTTPS Git 仓库导入，新建与编辑 SKILL.md，保存完整附属文件。草稿与已发布版本分开，Claude Code、Codex、Pi 可使用符号链接或副本部署；提供写入预览、停用、来源更新、版本恢复及最近部署恢复。该功能由 Muster 独立实现，不对接 Magpie。
- **统一 Agent 清单**：「设置 → Agent 管理」控制规则、会话、配置、技能、项目统计、通知和清理范围。安装检测区分可执行程序／有效应用包与残留配置。自定义清单立即生效并在重启后保留，取消勾选不删除数据或现有技能部署。
- **外观与交互**：支持跟随系统、浅色和深色外观，修复切换后的混色；新增跟随系统／开启／关闭减弱动态效果，统一按钮反馈、控件样式和辅助文字对比度。
- **状态与文件保护**：清除过期保存提示，避免切换视图或刷新时丢失草稿。技能部署校验目标归属和外部修改，支持中断恢复；清理保留未纳入展示范围的 Agent 进程归属信息，避免误认进程。

## 验证

- 本地通过 245 项测试，覆盖全局范围、项目归属、技能导入与部署恢复、配置草稿、规则应用和窗口导航等行为。
- 原生界面验证了 420pt 小窗口的规则／配置操作、四个目标开关、固定操作栏、中文和英文舒适布局，以及深浅色显示。
- 已验证规则与配置的原生 `⌘S` 保存、大窗口定位、未保存改动保护，以及公开 Git 仓库的技能候选发现。
- 发布构建另检查应用版本、代码签名、安装包及 SHA-256；远端 CI 结果见对应 Release。

## 安装与更新

- 支持 **macOS 14 及以上、Apple Silicon（arm64）**。
- 下载 `Muster-1.1.0.dmg`，退出旧版后把 `Muster.app` 拖入 `/Applications` 替换。原有会话标注、项目、规则、预设及设置保存在应用包之外。
- 下载同版本的 `Muster-1.1.0.sha256`，与 DMG 放在同一目录，运行 `shasum -a 256 -c Muster-1.1.0.sha256` 校验。
- 本安装包沿用 ad-hoc 签名，未做 Apple 公证。首次打开可能需要在「系统设置 → 隐私与安全性」允许打开。
- 本次没有配置发布签名密钥，应用内自动安装更新仍未启用，请通过 DMG 手动升级。

## 当前限制

- 原生模型表单仍只支持 Codex 和 Pi；其他已支持的配置保留原文件入口。
- 技能的项目级部署、Skill 路由和技能市场未包含在本版；远程导入目前支持公开 HTTPS Git 仓库，未提供 SSH 或私有仓库认证界面。
- 共享技能目录可能被多个 Agent 读取，界面会提示共同可见范围；文件部署成功不代表运行中的 Agent 已加载，需要时重新加载或新开会话。
- 应用仅展示并管理已支持的 Agent 类型，非标准安装位置仍可能需要通过环境诊断排查。
