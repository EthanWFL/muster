# Muster 1.3.0

Muster 的管理窗口新增「对话」。你可以用自己的 OpenAI API 密钥查询本机项目和会话，并从结果中打开正在运行的客户端。

## 对话

- 在「设置 → 对话模型」保存 API 密钥、选择模型并测试连接。密钥保存在 macOS 钥匙串。
- 用自然语言按项目、Agent、会话标题、最后活动日期和运行状态查询。匹配超过 5 条时会提示还有更多结果。
- 回复逐步显示，可以随时停止。失败或停止后可重试最后一条回复，输入框里的草稿会保留。
- 查询受「Agent 管理」范围限制。消息及匹配的项目和会话摘要会发送给 OpenAI，Agent 会话原文保留在本机。打开客户端需要你点击确认。

## 自 1.2.0 以来的其他更新

- 项目支持桌面快捷轮盘，可以切回 VS Code 项目窗口，或使用网站、剪贴板入口。
- 会话支持定位 Warp 面板，菜单栏运行计数更紧凑。
- 调整熊猫图标与窗口动效，完善技能单源管理和旧版迁移。

支持 macOS 14 及以上、Apple Silicon。DMG 附有 Ed25519 更新签名和 SHA-256 校验文件。应用采用 ad-hoc 代码签名，尚未经过 Apple 公证。
